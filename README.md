# College Enquiry Chatbot

## 1. Introduction
The College Enquiry Chatbot is a web-based application designed to help students get basic information about college courses, admission procedures, fees, eligibility and contact details.

## 2. Problem Statement
Students often face difficulties getting college information because they need to contact the college office or visit the campus. This process can take time.

## 3. Proposed Solution
The proposed system provides an online chatbot that answers common student enquiries quickly through a simple and user-friendly interface.

## 4. Objectives
- To provide quick college information.
- To reduce repetitive enquiries.
- To make information easily accessible.
- To collect student satisfaction feedback.
- To develop a simple web-based chatbot.

## 5. Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Data Storage: JSON
- Development Tool: Visual Studio Code
- Browser: Google Chrome

## 6. Key Features
- Interactive chatbot interface.
- Course information.
- Admission information.
- Fee details.
- Eligibility information.
- College contact information.
- Student feedback collection.

## 7. Working of the System
1. Student opens the chatbot website.
2. Student enters a question.
3. JavaScript sends the question to the Flask backend.
4. Flask processes the question.
5. The system searches for a matching predefined response.
6. The answer is displayed on the website.
7. Student submits Yes/No feedback.
8. Feedback is stored in a JSON file.

## 8. Project Structure
- app.py – Flask backend application.
- templates/index.html – Chatbot user interface.
- feedback.json – Stores student feedback.
- README.md – Project documentation.

## 9. Installation and Execution
1. Install Python.
2. Install Flask using:

   `pip install flask`

3. Open the project folder in VS Code.
4. Run the application:

   `python app.py`

5. Open the following URL in your browser:

   `http://127.0.0.1:5000`
